# EAMStream

**EAMStream** — a technical blog about IBM Maximo / Enterprise Asset Management by Jacky Qiu (10+ years Maximo/EAM).

- Built with [Hugo](https://gohugo.io) (extended v0.168.0) + [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme
- 27 articles migrated from Medium, covering Maximo automation scripts, MIF integration, REST APIs, MAS 9 and more
- Live at: https://eamstream.com

## Local preview

```bash
hugo server -D
```

## Deploy

Connected to Cloudflare Pages: build command `hugo`, output directory `public`, env `HUGO_VERSION=0.168.0`.
